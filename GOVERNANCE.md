# Governance

Undreamt Website is developed in public. Anyone may open an issue, propose a change, or submit a pull request, subject to the [Code of Conduct](CODE_OF_CONDUCT.md).

## Decisions and review

Routine changes are discussed and reviewed through GitHub issues and pull requests. Maintainers are responsible for final review and merge decisions, releases, and repository settings. When a proposal has significant impact on project direction or ongoing maintenance, discuss it in an issue before implementation.

Maintainers should explain decisions in the relevant public discussion and consider feedback from contributors. Participation in the project does not guarantee that a proposal will be accepted.

## Changes to this policy

Changes to this governance policy should be proposed in a public pull request and reviewed by a maintainer.
