# Undreamt Website

The public website for Undreamt, a community building open source software and projects that have never been dreamt.

## Development

### Requirements

- Node.js 22.12 or newer
- npm

### Get started

```bash
git clone https://github.com/undreamt-oss/undreamt-website.git
cd undreamt-website
npm install
npm run dev
```

Vite prints the local URL when the development server starts. The website does not require API keys or other secrets for local development.

### Available commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run lint` | Check TypeScript types |
| `npm run build` | Create the production build in `dist/` |
| `npm run preview` | Serve the production build locally |
