# Contributing

Thanks for helping improve the Undreamt website. Contributions of code, documentation, and bug reports are welcome.

## Before opening an issue

- Search existing issues to avoid duplicates.
- For a bug, include the page, steps to reproduce it, and the browser or device where it occurred.
- For a larger change, open an issue first so maintainers and contributors can discuss the direction.

## Development workflow

1. Fork the repository and create a branch for your change.
2. Install dependencies with `npm install` and start the site with `npm run dev`.
3. Keep changes focused and follow the existing code style.
4. Before submitting, run `npm run lint` and `npm run build`.
5. Open a pull request with a clear summary, related issue links, and screenshots for visible website changes.

Do not commit credentials, generated build output, or dependency directories. Changes to dependencies should be explained in the pull request.

## Pull request review

Pull requests are reviewed in the open. A maintainer may ask for changes or clarification before merging. By submitting a contribution, you agree that it is provided under the repository's [Apache-2.0 license](LICENSE).

All contributors are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
