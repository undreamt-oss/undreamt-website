# Security Policy

Please report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/undreamt-oss/undreamt-website/security/advisories/new). Do not post vulnerability details in a public issue.

Include the affected commit or release, the affected page or component, steps to reproduce the issue, and its potential impact. Redact credentials and personal information from reports.

The maintainers will acknowledge reports as soon as practical and coordinate next steps with the reporter. Use the regular issue tracker for non-security bugs and feature requests.
